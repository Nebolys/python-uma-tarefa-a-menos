# Python — Uma Tarefa a Menos

Repositório oficial de materiais complementares do ebook **Python — Uma Tarefa a Menos**, publicado pela **Nebolys**.

## Código-fonte e materiais

Os pacotes completos de código-fonte serão disponibilizados na secção **Releases** deste repositório.

Cada ficheiro será identificado pelo **idioma** e pela **versão/edição** correspondente do ebook, por exemplo:

- `python-uma-tarefa-a-menos-pt-PT-v1.0.0.zip`
- `python-uma-tarefa-a-menos-en-US-v1.0.0.zip`
- `python-uma-tarefa-a-menos-fr-FR-v1.0.0.zip`

Utilize sempre o pacote que corresponda ao idioma e à edição do seu exemplar.

## Chave de acesso

Os pacotes distribuídos pela Nebolys podem estar protegidos por uma chave de acesso.

A instrução para obter essa chave encontra-se no próprio ebook, junto da ligação para os materiais complementares.

A referência deve usar uma localização estável do conteúdo, por exemplo:

- capítulo;
- secção;
- elemento textual concreto.

Evita-se usar número de página porque a paginação pode variar em EPUB.

## Versões

Os materiais seguem versionamento por edição/revisão.

Atualizações e correções serão publicadas como novas **Releases**.

## Importante

Os ficheiros automáticos **Source code (zip)** e **Source code (tar.gz)** que o GitHub apresenta em cada Release correspondem apenas ao conteúdo público do repositório e **não** aos pacotes oficiais de materiais do ebook.

Para obter os materiais corretos, descarregue sempre o ficheiro anexado pela Nebolys à Release correspondente ao seu idioma e edição.
